<!DOCTYPE html>

<html lang="ko">

<head>

    <meta charset="UTF-8">

    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <title>Chrome으로 이동 중...</title>

    <script>

        window.onload = function() {

            var userAgent = navigator.userAgent.toLowerCase();

            var domain = "dan.shinan.or.kr";

            

            // 1. 아이폰 (iOS)

            if (userAgent.indexOf("iphone") > -1 || userAgent.indexOf("ipad") > -1 || userAgent.indexOf("ipod") > -1) {

                // 아이폰 크롬 앱 호출 (https인 경우 googlechromes:// 사용)

                window.location.href = "googlechromes://" + domain;

                

                // 만약 크롬 앱이 설치되어 있지 않다면 1.5초 뒤 사파리(기본 브라우저)에서 https로 열기

                setTimeout(function() {

                    window.location.href = "https://" + domain;

                }, 1500);

            } 

            // 2. 안드로이드

            else if (userAgent.indexOf("android") > -1) {

                // 안드로이드 크롬 앱 강제 호출 intent (scheme=https로 변경)

                window.location.href = "intent://" + domain + "#Intent;scheme=https;package=com.android.chrome;end";

            } 

            // 3. 기타 기기 (PC 등)

            else {

                // 일반 브라우저에서는 바로 https로 이동

                window.location.href = "https://" + domain;

            }

        };

    </script>

</head>

<body style="text-align: center; padding-top: 50px; font-family: sans-serif;">

    <p>Chrome 브라우저로 이동하고 있습니다...<br>잠시만 기다려 주세요.</p>
